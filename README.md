# Lodgical — public builds

**0.9.0 (build 246, d328697)**. The `stable` branch holds the newest numbered release, `edge` the newest build.

**Browser extension:** download `lodgical-public.zip`, unzip it to a folder you'll keep, open
`chrome://extensions`, turn on *Developer mode*, click *Load unpacked* and choose that folder. To update, unzip the
new zip over the same folder and click the reload icon on Lodgical's card — your data and sign-in stay.

**Android:** open `lodgical-android.apk` on the phone and allow the install. After that the app updates itself
(Settings → App version).
